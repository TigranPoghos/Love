# Сердце → вихрь → портрет

Откройте `index.html` двойным нажатием в современном браузере (Chrome, Edge, Firefox). Интернет и установка пакетов не нужны. Нажмите «Нажми на меня» или на сердце. Кнопка повтора появляется после сборки портрета.

Для GitHub Pages загрузите **содержимое этой папки** в корень репозитория, включая `assets/portrait.jpg` и `assets/portrait-pixels.js`. Если загрузить только ZIP или пропустить один из этих файлов, анимация не загрузится. Фотография в публичном репозитории доступна всем.

Для замены фотографии замените `assets/portrait.jpg` и заново создайте `assets/portrait-pixels.js` из неё (простая замена JPG оставит старые цвета частиц). Скрипт использует WebGL2, а фото проявляется в конце. Длительность анимации после нажатия — около 9 секунд.
