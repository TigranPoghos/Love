# Сердце → вихрь → портрет

Откройте `index.html` двойным нажатием в современном браузере (Chrome, Edge, Firefox). Интернет и установка пакетов не нужны. Нажмите «Нажми на меня» или на сердце. Кнопка повтора появляется после сборки портрета.

Используется WebGL2; нужен браузер с включённым аппаратным ускорением. Если WebGL2 недоступен, появится исходная фотография и объяснение. Звук создаётся браузером после нажатия кнопки и не требует аудиофайлов.

Для замены фотографии положите JPG под именем `assets/portrait.jpg` (другая пропорция тоже поддерживается). Сцена: живое сердце → сжатие → вихрь → постепенная сборка точек → фотография. Продолжительность после нажатия около 9 секунд.
